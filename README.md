# Sense2Sim Universe

https://ambient-intelligence-lab-umich-eecs.github.io/Sense2Sim_Universe/

The pages every Sense2Sim paper page links to:

- `index.html`: the first page, a scroll-driven way into the two pages below.
- `pages/universe/`: the Sensing Universe, the SenseWeaver knowledge base of sensing papers, as a map, a graph and a table.
- `pages/world/`: the Sensing World, everyday spaces in 3-D, each with the papers that sense in it.
- `semantic/`: the search by meaning used by both pages; it runs in the browser and loads after the page is ready.

The 3-D models come from the SenseWeaver asset pack; their credits and licences are in `CREDITS.md`.
